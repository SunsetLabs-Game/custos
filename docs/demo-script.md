# Demo video shot list (≤ 5 minutes)

Target: one continuous narrative, not a feature tour. Judges see this before
anything else.

1. **Hook (15s)** — one sentence on the problem: cross-border USDT scams, why
   cloud-based detection can't touch the sensitive data involved.
2. **Scenario setup (30s)** — a chat screenshot/text from a "fake investment
   platform" pig-butchering script, in a language the demo persona doesn't
   speak.
3. **Paste into Custos (30s)** — show the address + chat context going in.
   Narrate: "nothing here leaves the device."
4. **TranslatePsy in action (45s)** — show the translated text appearing,
   explicitly call out that this is the QVAC Psy model, not a cloud
   translation API.
5. **Detection result (45s)** — risk level, matched pattern, plain-language
   summary.
6. **Friction/block before signing (45s)** — attempt to send in the WDK
   wallet flow, show the interception screen, show that Critical risk cannot
   be overridden (only cancel).
7. **P2P risk sync (30s, if the stretch goal landed)** — a second device/peer
   already has this address reported; show it arriving via Hyperswarm without
   a central server.
8. **Close (20s)** — restate: on-device QVAC + TranslatePsy for detection,
   WDK for the wallet, Pears for decentralized sync. Link to repo.

Recording notes:
- Screen-record the actual app, not slides, wherever possible — "Completion"
  and "Technical" together are 45% of the score.
- Keep it unlisted on YouTube per the rules, and double check the link works
  in a private/incognito window before submitting (no credentials required).
